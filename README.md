# Led_Control

iPixel Color 96×16 LED 的繁體中文控制網頁（Web Bluetooth）。

- 網址：https://self-study-junior.github.io/Led_Control/
- iPhone 請用 Bluefy 瀏覽器開；Android／電腦用 Chrome 或 Edge
- 功能：連線、開關、亮度、遙控器動畫語言碼、繁體跑馬燈（可局部變色）、圖庫一鍵送出、送自己的圖片／GIF
- 協定依 [pypixelcolor](https://github.com/lucagoc/pypixelcolor)（MIT）

接手開發：先讀 `HANDOFF.md` 與 `.claude/skills/led-control/SKILL.md`。
